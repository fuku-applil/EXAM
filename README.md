# 宅建合格アプリ「タッケン3ヶ月」

**宅地建物取引士(宅建士)試験に、初学者が3ヶ月で合格する**ことだけを目的にした学習アプリです。
ブラウザで `index.html` を開くだけで動きます(インストール・登録不要、データは端末内に保存)。

---

## 1. まず知っておくこと(試験の基礎知識)

| 項目 | 内容 |
|---|---|
| 試験日 | 毎年10月の第3日曜(2026年は **10月18日** 想定) |
| 形式 | 四肢択一 × 50問、マークシート、2時間 |
| 合格ライン | 例年 **50点中 34〜38点前後**(約7割) |
| 出題内訳 | 宅建業法 **20問** / 権利関係(民法など) **14問** / 法令上の制限 **8問** / 税・その他 **8問** |
| 必要学習時間 | 初学者で300〜400時間(3ヶ月なら **1日3〜4時間**) |

### 合格戦略の核心(このアプリの設計思想)

満点は要りません。**38点を取る配点戦略**で勉強します。

| 分野 | 出題数 | 目標 | 方針 |
|---|---|---|---|
| 宅建業法 | 20問 | **18点** | 暗記中心で最も点になりやすい。ここに一番時間をかける |
| 法令上の制限 | 8問 | **6点** | 数字の暗記ゲー。表で覚えて過去問で固める |
| 税・その他 | 8問 | **6点** | 頻出パターンが決まっている。直前期に集中 |
| 権利関係 | 14問 | **8点** | 深追い禁止。頻出テーマだけ取り、難問は捨てる |
| **合計** | 50問 | **38点** | 合格ラインを余裕をもって超える |

初学者が失敗する典型は「民法(権利関係)から始めて挫折する」パターンです。
このアプリは**宅建業法から始める**カリキュラムになっています。

---

## 2. 3ヶ月学習ロードマップ(アプリに内蔵)

- **第1〜4週(7月中旬〜8月中旬):インプット期**
  宅建業法を一気に仕上げる+権利関係の頻出テーマだけ着手。毎日一問一答。
- **第5〜8週(8月中旬〜9月中旬):アウトプット期**
  法令上の制限・税その他を暗記。過去問を分野別に回す。間違えた問題は自動で「弱点ノート」へ。
- **第9〜12週(9月中旬〜試験日):仕上げ期**
  模試モードで時間配分の練習。弱点ノートの潰し込み。統計・法改正は最後の1週間で暗記。

## 3. アプリの機能

| 画面 | 機能 |
|---|---|
| 🏠 ホーム | 試験日カウントダウン、今日やるべきタスクの提示、学習状況サマリー |
| 🗓 学習計画 | 12週間ロードマップをチェックリスト化。進捗が保存される |
| ⭕ 一問一答 | 分野別の○×クイズ。1問ごとに解説つき。正誤は自動記録 |
| 🔁 弱点復習 | 間違えた問題が「1日後→3日後→7日後」に自動で再出題(間隔反復) |
| 📝 ミニ模試 | 本試験と同じ四肢択一を制限時間つきで演習 |
| 📊 成績 | 分野別の正答率をグラフ表示。弱い分野が一目で分かる |

すべての記録はブラウザの localStorage に保存されます(サーバー不要・オフラインOK)。

## 4. 使い方

1. このフォルダの **`index.html` をダブルクリック**してブラウザで開く
2. ホーム画面の「今日のタスク」に従って学習する
3. 毎日「一問一答」→ 間違えたら翌日以降「弱点復習」に出てくるので必ず消化する
4. 9月以降は週1回「ミニ模試」で時間感覚を作る
